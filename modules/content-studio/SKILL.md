# Content Studio Quick

## ใช้กับนักเรียน

ทำตาม `INSTRUCTOR.md` ทุกขั้น (เริ่มที่หัวข้อ "เริ่มทุกครั้ง") และอัปเดต `PROGRESS.md`
ถ้าชุดนี้ถูกติดตั้งเป็น skill ให้สร้างโฟลเดอร์งาน `~/Documents/Content-Studio` ตาม `INSTRUCTOR.md` ข้อ 1 ก่อน

## ใช้กับครู (เตรียมคลาส / แจกชุด)

- แจก: `python3 tools/pack.py --out <ที่เก็บ zip นอก git>` (ตัดไฟล์ `my-*` ออกเอง และไม่ยอมแพ็กถ้าเจอลิงก์ Make / key / id บัญชี) · นักเรียนแตกแล้วพิมพ์ "เริ่ม" (`START_HERE_TH.md`)
- ก่อนแจกทุกครั้ง: `python3 -m unittest discover -s tests -v` และ `python3 tools/build_blueprints.py --check` ต้องผ่าน
- แก้ scenario: แก้ `tools/build_blueprints.py` แล้วรันใหม่ · ห้ามแก้ `blueprints/studio.json` มือ · ห้ามใส่ id บัญชีใด ๆ ในไฟล์ที่แจก
- สำเนาของครูที่ต่อบัญชีจริง: `build_blueprints.py --teacher <ids.json> --out <นอกโฟลเดอร์นี้>` แล้วสร้างผ่าน Make MCP (ไฟล์ teacher ใส่ `maximum_runs_per_minute` ให้เอง กัน Make ปิด scenario)
- เดโม่หน้าห้องโดยไม่ยิงของจริง: `python3 tests/mock_make.py` แล้วเปิด `http://127.0.0.1:5480/webapp/studio.html`

## ข้อเท็จจริงที่ทดสอบแล้ว

- `ping` และ `caption` (gpt-4.1, JSON mode) รันจริงใน Make ผ่าน · แคปชันใช้ราว 4 วินาที 3 เครดิต Make
- ทางพังของ `post` และ `image` ตอบ `{"ok":false,"error":…}` และ scenario ไม่ถูกนับเป็น error (มี error handler + Ignore)
- เว็บผ่านครบ 4 ขั้นกับ Make จำลอง: ทดสอบการเชื่อม → ทำรูป → แคปชัน 3 แบบ (เติมคำปิดท้ายเองถ้า AI ลืม) → ตั้งเวลา (ส่ง epoch ms ถูกต้อง)
- 24 ต.ค. (พี่ง้วงอนุมัติ) ผ่านเว็บจริงทั้งสาย: AI ทำรูปจากโลโก้ 1 รูป (💎 4:5 ได้ 1024×1280 ใน 28 วินาที 3 เครดิต Make ตัวหนังสือไทยบนภาพสะกดถูก)
  → ตั้งเวลาโพสต์บนเพจทดสอบ → อ่านกลับจาก Facebook ตรง (ข้อความ เวลา 08:00 รูป 4:5) → ลบแล้วอ่านซ้ำไม่พบ
- ทดสอบทำรูปหรือโพสต์จริงครั้งต่อไป ต้องขออนุมัติก่อนทุกครั้ง (เสียเงิน / ขึ้นเพจจริง)
- gpt-image รุ่นใหม่ต้อง Verify องค์กร OpenAI ก่อน ไม่งั้นทำรูปไม่ผ่าน (แคปชันยังใช้ได้)
- Facebook ตั้งเวลาได้ล่วงหน้า 20 นาที–28 วัน (เว็บกันให้แล้ว)
