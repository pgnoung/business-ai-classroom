# เริ่มที่นี่ · Content Studio ระบบโพสต์เพจของร้านคุณ

เว็บทำโพสต์ของร้านคุณเอง: เล่าเรื่อง → ใส่รูปหรือให้ AI ทำรูป → AI เขียนแคปชัน 3 แบบ → โพสต์เลยหรือตั้งเวลาขึ้นเพจ
ทุกอย่างวิ่งผ่าน Make ในบัญชีของคุณเอง ใช้เวลาตั้งค่ารวมราว 30 นาที

## เตรียมมา 3 อย่าง

1. บัญชี make.com (แบบฟรีได้)
2. OpenAI API key ที่มีเครดิต · ถ้าอยากให้ AI ทำรูป ต้องกด Verify องค์กรใน OpenAI ก่อน
3. บัญชี Facebook ที่เป็นแอดมินของเพจ

## เริ่ม 2 ขั้น

1. แตก zip แล้วเปิดโฟลเดอร์นี้ใน Claude Code, Claude (Cowork) หรือ Codex
2. พิมพ์คำว่า **เริ่ม**

AI จะถามข้อมูลร้านทีละข้อ พาประกอบ Make ทีละคลิก สร้างเว็บของร้านคุณ แล้วพาโพสต์แรกด้วยกัน
ถ้าหยุดกลางทาง กลับมาพิมพ์ **ทำต่อ** ได้เลย ระบบจำไว้ใน `PROGRESS.md`

## ติดตั้งเป็น skill ก็ได้

คัดลอกทั้งโฟลเดอร์ไปไว้ที่ `~/.claude/skills/content-studio` (Claude) หรือ `~/.codex/skills/content-studio` (Codex)
แล้วพิมพ์ในแชตใดก็ได้ว่า **ติดตั้ง Content Studio**

## ของส่วนตัว อย่าส่งต่อ

`my-studio.html` (มีลิงก์ Make ของคุณ ใครได้ไปโพสต์ลงเพจคุณได้) และ `my-shop.json`
