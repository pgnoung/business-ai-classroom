# เช่า VPS (เซิร์ฟเวอร์ที่เปิดตลอด 24 ชม.)

AI แอดมินต้องอยู่บนเครื่องที่เปิดตลอดและมีที่อยู่บนอินเทอร์เน็ต เพื่อให้ LINE ส่งข้อความลูกค้ามาได้ทุกเวลา

## สเปกที่ต้องการ

| รายการ | ขั้นต่ำ | แนะนำ |
| --- | --- | --- |
| ระบบ | Ubuntu 24.04 LTS (หรือ 22.04 / Debian 12) | Ubuntu 24.04 |
| RAM | 2 GB | 4 GB |
| ดิสก์ | 20 GB | 40 GB ขึ้นไป |
| อื่น ๆ | มี IPv4 สาธารณะ · เข้าด้วย root ได้ | ศูนย์ข้อมูลในเอเชียที่ใกล้ไทยที่สุดที่มีให้เลือก |

ใช้ได้ทุกเจ้าที่ให้ Ubuntu + root (เช่น Hostinger, DigitalOcean, Vultr, Linode, ผู้ให้บริการในไทย) ค่าใช้จ่ายโดยทั่วไปหลักร้อยบาทต่อเดือน
— ให้ผู้ใช้ดูราคาปัจจุบันบนเว็บผู้ให้บริการเอง อย่ายืนยันราคาแทน

## พาผู้ใช้เช่า (ผู้ใช้กดจ่ายเอง)

1. ให้ผู้ใช้เลือกผู้ให้บริการและสมัครบัญชีเอง
2. ตอนสร้างเครื่อง: เลือก **Ubuntu 24.04** (แบบเปล่า ไม่ต้องมีแผงควบคุม/แอปติดมา) · ตั้ง **รหัส root** ที่เดายาก แล้วจดเก็บเอง
   (ห้ามส่งรหัสนี้ในแชท) · ถ้าระบบถามเรื่อง SSH key ข้ามได้ เดี๋ยวตัวช่วยส่งกุญแจให้เอง
3. ผู้ใช้กดจ่ายเงินเอง แล้วรอเครื่องพร้อม (ไม่กี่นาที)
4. ขอให้ผู้ใช้บอก **IP ของเครื่อง** (ตัวเลข 4 ชุด เช่น 203.0.113.5) — IP ไม่ใช่ความลับ ส่งในแชทได้
5. ถ้าผู้ให้บริการมี "ไฟร์วอลล์ของแผงควบคุม" ให้เปิดพอร์ต 22, 80, 443 (ตัวติดตั้งเปิดไฟร์วอลล์ในเครื่องให้เองแล้ว)

## ชื่อเว็บ (โดเมน)

- ไม่มีโดเมน: ใช้ได้เลย ตัวติดตั้งตั้งชื่อฟรีแบบ `203-0-113-5.sslip.io` ให้อัตโนมัติ (ชี้มาที่ IP นี้) พร้อม HTTPS
- มีโดเมนของร้าน: ให้ผู้ใช้สร้างระเบียน **A** เช่น `admin.ร้าน.com → IP ของ VPS` ที่ผู้ให้บริการโดเมน รอ 5–30 นาที
  แล้ว `ai-admin connect <IP> --domain admin.ร้าน.com` และ `ai-admin deploy` ใหม่ (ต้องเปลี่ยน Webhook ใน LINE ด้วย `ai-admin line`)

## ความปลอดภัยของเครื่อง

ตัวติดตั้งทำให้แล้ว: ไฟร์วอลล์เปิดแค่ 22/80/443 · โปรแกรมรันด้วยผู้ใช้ระบบที่ไม่มีสิทธิ์ root · ค่าลับอยู่ในไฟล์ที่อ่านได้เฉพาะระบบ ·
เข้า VPS ด้วยกุญแจ ไม่ต้องใช้รหัส root อีก (ผู้ใช้จะปิดการล็อกอินด้วยรหัสผ่านทีหลังได้ ถ้าคุ้นเคยแล้ว)
