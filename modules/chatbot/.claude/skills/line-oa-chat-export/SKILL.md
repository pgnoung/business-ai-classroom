# LINE OA Chat Export — แชทเก่าของร้าน → วัตถุดิบเทรน

## ต้องมี

- ผู้ใช้เป็นแอดมินของ LINE OA ร้าน และ**ล็อกอิน chat.line.biz เองใน Chrome** (AI ไม่แตะรหัส ไม่ดึงคุกกี้/โทเคน)
- AI ที่ควบคุมแท็บ Chrome ของผู้ใช้ได้ (เช่น Claude in Chrome หรือเบราว์เซอร์ของ Codex ที่ใช้โปรไฟล์ผู้ใช้)
  — เบราว์เซอร์แยกที่ไม่มี session ของผู้ใช้ใช้ไม่ได้
- ถ้าไม่มีเครื่องมือควบคุมเบราว์เซอร์: ให้ผู้ใช้คัดลอกแชทตัวอย่างมาวางเอง (ปิดชื่อ/เบอร์ก่อน) แล้วข้ามไปขั้น 4

## กติกาเหล็ก

1. **อ่านอย่างเดียว** — ห้ามคลิกเปิดห้องแชท (ข้อความจะกลายเป็น "อ่านแล้ว" ถาวร) ห้ามส่งข้อความ ติด/ลบแท็ก ปิดงาน หรือแก้อะไร
2. **ข้อมูลลูกค้าอยู่ในเครื่องผู้ใช้เท่านั้น** — `chat-export/` ไม่ถูก commit ห้ามอัปโหลด ห้ามแชร์ ห้ามพิมพ์เนื้อแชทดิบออกจอเกินจำเป็น
3. **ใช้แต่ไฟล์ที่ปิดข้อมูลแล้ว (`chat-export/clean/`)** ในการสกัด และ**ห้ามคัดลอกชื่อ เบอร์ ที่อยู่ของลูกค้า**ลง `business/` หรือไฟล์เคส
4. สคริปต์เก็บแค่ข้อความ (ใครพูด ชนิด ตัวอักษร เวลา) ไม่เก็บชื่อ รูปโปรไฟล์ โน้ต หรือแท็กของลูกค้า
5. ลบ `chat-export/raw/` เมื่อสกัดเสร็จ ถ้าผู้ใช้ไม่ต้องการเก็บไว้ (ถามก่อน)

## ขั้นตอน

1. **เปิดตัวรับในเครื่อง** — `ai-admin chat-sink` (ทิ้งหน้าต่างไว้) จดค่า `SINK_TOKEN=` ที่พิมพ์ออกมา (เป็นรหัสของรอบนี้ ไม่ใช่รหัส LINE)
2. **ให้ผู้ใช้เปิด** `https://chat.line.biz` ใน Chrome เลือกบัญชีร้าน (URL ต้องมี `U...` ยาว 33 ตัว) — ไม่ต้องเปิดห้องใด
3. **รันสคริปต์ในแท็บนั้น** — อ่าน `starter/line-export/browser-export.js` แก้ `TOKEN` (และ `SINCE_DAYS` / `MAX_ROOMS` ถ้าต้องการ)
   แล้วรันทั้งก้อนด้วยเครื่องมือ javascript ของเบราว์เซอร์ · ✅ ต้องได้ `เก็บใหม่ N ห้อง` และตัวรับพิมพ์ `เบราว์เซอร์แจ้งว่าเก็บครบแล้ว`
   ล้มกลางทาง (session หมด) → ให้ผู้ใช้ล็อกอินใหม่แล้วรันซ้ำ ระบบข้ามห้องที่เก็บแล้วเอง
4. **ปิดข้อมูลส่วนตัว** — ปิดตัวรับ (Ctrl+C) แล้ว `ai-admin chat-redact` → ได้ `chat-export/clean/`:
   `conversations.md` (อ่าน) · `conversations.jsonl` (ประมวลผล) · `customer-openers.txt` (ประโยคเปิดของลูกค้า)
5. **สกัดเป็นวัตถุดิบ** (อ่านจาก `clean/` เท่านั้น) แล้วเสนอผู้ใช้ยืนยันก่อนเขียนไฟล์ใด:
   - **FAQ** — คำถามที่ซ้ำบ่อย 10–20 ข้อ + คำตอบที่ร้านตอบจริง → `business/faq.json` (ราคาต้องตรง `products.json`)
   - **น้ำเสียง** — ร้านตอบสั้น/ยาว ใช้คำลงท้ายแบบไหน อีโมจิไหม → ปรับ `tone` ใน `business.json` ให้เป็นตัวอย่างจริง
   - **สิ่งที่ร้านส่งต่อให้คน** — เรื่องที่แอดมินตอบเองทุกครั้ง (โอนเงิน เคลม) → `handoffRules`
   - **เคสจำลอง** — ประโยคเปิดจริง 10–20 แบบ (เปลี่ยนรายละเอียดส่วนตัวเป็นของสมมติ) → `harness-cases.json` (skill `chat-harness`)
6. `ai-admin import` (ดูแผน) → `import --apply` → `ai-admin harness harness-cases.json` เพื่อดูว่า AI ตอบคำถามจริงของลูกค้าได้แค่ไหน

## รู้ไว้

- LINE เก็บประวัติแชทย้อนหลังราว 2–3 ปี ห้องที่เงียบนานกว่านั้นอาจไม่มีข้อความ
- `ปิดข้อมูลอัตโนมัติ` จับเบอร์ อีเมล ลิงก์ เลขบัญชี เลขบัตร และข้อความที่หน้าตาเป็นที่อยู่ — ชื่อคนที่ลูกค้าพิมพ์เองจับไม่ได้ทั้งหมด
  จึงต้องยึดกติกาข้อ 3 เสมอ
- หน้าเว็บ chat.line.biz เปลี่ยนได้โดยไม่แจ้ง ถ้าสคริปต์แจ้งว่าอ่านไม่ได้ทั้งที่ล็อกอินแล้ว ให้หยุดและบอกผู้ใช้ อย่าลองคลิกในหน้าแทน
- ข้อมูลที่ได้เป็นของร้านผู้ใช้เอง ใช้ปรับบริการของร้านเท่านั้น ตามนโยบายความเป็นส่วนตัวที่ร้านแจ้งลูกค้า
