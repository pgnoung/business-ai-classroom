# Chat Harness — จำลองแชทเป็นชุด

**ของจริงทุกอย่าง ยกเว้น 2 จุด**: LINE ถูกดักไว้ในเครื่อง (ไม่มีอะไรถึงลูกค้า) และฐานข้อมูลเป็นสำเนา (ไม่แตะของจริง)
ข้อความวิ่งผ่าน webhook เส้นเดียวกับลูกค้าจริง จึงเห็นทั้งคำตอบ การส่งรูป การส่งต่อคน และข้อความแจ้งทีม

## ใช้

```
ai-admin harness harness-cases.json                 # ทั้งไฟล์
ai-admin harness harness-cases.json --only "ชื่อเคส"   # เคสเดียว ตอนกำลังแก้
```
(macOS/Linux: `bash ai-admin.sh harness …` · Windows: `powershell -ExecutionPolicy Bypass -File ai-admin.ps1 harness …`)

ผลอยู่ที่ `harness-reports/<เวลา>/report.md` (อ่านง่าย) และ `report.json` บนเครื่องผู้ใช้ — เปิด report.md ให้ผู้ใช้ดูทุกครั้ง

## ไฟล์เคส

เริ่มจาก `harness-cases.example.json` คัดลอกเป็น `harness-cases.json` แล้วแก้ให้เป็นสินค้าของร้าน

```json
[{ "name": "ถามราคาลาเต้", "turns": ["ลาเต้ร้อนราคาเท่าไหร่คะ"],
   "expect": { "mustInclude": ["65"], "mustNotInclude": ["ส่วนลด"], "handoff": false } }]
```
- `turns` = ข้อความลูกค้าตามลำดับ (สูงสุด 12 ต่อเคส) · แต่ละเคสเป็นลูกค้าคนใหม่ ความจำไม่ปนกัน
- `expect` ไม่ใส่ก็ได้ (อ่านเอง) · `mustInclude` / `mustNotInclude` เทียบกับคำตอบทุกบับเบิลรวมกัน · `handoff` = ห้องถูกส่งต่อให้คนหรือไม่
- เพดาน 30 เคสต่อรอบ (กันค่าใช้จ่ายบานปลาย) · `--max-cases` ปรับได้เมื่อผู้ใช้ยินยอม

## ที่มาของเคสที่ดี

1. คำติจากเจ้าของร้าน (ดู skill `ai-admin-training`) — หนึ่งคำติ = หนึ่งเคสที่ล็อกไว้
2. คำถามเปิดบทสนทนาจริงของลูกค้า จาก `chat-export/clean/customer-openers.txt` (skill `line-oa-chat-export`)
   — เปลี่ยนชื่อ/เบอร์/ที่อยู่ให้เป็นของสมมติก่อนใส่ไฟล์เคส
3. ชุดเคสพื้นฐานใน `harness-cases.example.json`

## อ่านผล 3 ชั้น (ตามลำดับ)

1. **มีอะไรหลุดถึงลูกค้าที่ไม่ควรหลุดไหม** — บรรทัด 🤖: ราคาที่ไม่อยู่ในรายการ โน้ตภายใน คำสัญญาที่ร้านไม่ได้ให้
2. **ระบบทำตามที่ AI พูดไหม** — AI บอก "เดี๋ยวทีมงานติดต่อกลับ" แล้วมีบรรทัด 📣 แจ้งทีม และห้องถูกส่งต่อจริงไหม
3. **น้ำเสียงและข้อเท็จจริง** — อ่านเอง ตัวเลขทุกตัวต้องตรวจกับ `business/`

เคสตก: อ่านคำตอบจริงก่อนเสมอ เกณฑ์อาจแคบเกิน (เช่นต้องการ "65 บาท" แต่ AI ตอบ "65.-") ปรับเกณฑ์ได้ แต่ห้ามปรับให้ผ่านเพื่อปิดปัญหาจริง

## ข้อควรรู้

- **เสียเงินจริง** ราว 1–3 บาทต่อเคส (รายงานบอกยอดจริงและ % cache ท้ายรอบ) · บอกผู้ใช้ก่อนรันชุดใหญ่
- ใช้ข้อมูลร้าน **ที่นำเข้าแล้ว** — แก้ `business/` แล้วต้อง `import --apply` ก่อนจำลอง ไม่งั้นทดสอบของเก่า
- ระบบจริงไม่สะดุดระหว่างจำลอง (รันอีกตัวบนพอร์ตแยก) · สำเนาฐานข้อมูลถูกลบทิ้งหลังจบรอบ
- รายงานอยู่ในเครื่องผู้ใช้เท่านั้น (`harness-reports/` ไม่ถูก commit)
- ข้อความ "(ไม่มีคำตอบถึงลูกค้า)" ไม่ใช่ความผิดพลาดเสมอไป — ถ้าห้องถูกส่งต่อให้คน AI จะเงียบตามดีไซน์
