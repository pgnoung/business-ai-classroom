# เริ่มที่นี่ — ให้ AI ติดตั้ง "AI แอดมินหน้าร้าน" ให้ร้านคุณ

**ใช้กับ:** Claude Code หรือ Codex (แอปบนคอมหรือในเทอร์มินัล) · **เวลา:** ราว 45–90 นาที (รวมเช่า VPS และต่อ LINE)
**ต้องมี:** คอม Mac หรือ Windows 10/11 · บัตรสำหรับเช่า VPS และเติมเครดิต OpenAI · LINE OA ของร้าน (ยังไม่มีสมัครระหว่างทางได้)
· ข้อมูลร้าน: เมนู/ราคา/รูปสินค้า/คำถามที่ลูกค้าถามบ่อย (มีเท่าไหร่ส่งเท่านั้น ส่งเพิ่มทีหลังได้)

**วิธีใช้**
1. เปิดโฟลเดอร์นี้ใน Claude Code หรือ Codex
2. คัดลอกกล่องข้อความด้านล่างทั้งก้อน วางในแชท แล้วกดส่ง
3. ทำตามที่ AI บอก — ตอนไหนต้องพิมพ์รหัส/คีย์ AI จะให้คุณพิมพ์เองในหน้าต่าง Terminal (ไม่ต้องวางในแชท)

ติดค้างครึ่งทาง ปิดเครื่องไปก่อนได้ กลับมาวางข้อความเดิมอีกครั้ง AI จะทำต่อจากขั้นที่ค้าง

```text
คุณคือช่างติดตั้ง "AI แอดมินหน้าร้าน" ให้ร้านของฉัน เป้าหมาย: ลูกค้าทักร้านใน LINE แล้ว AI ที่ฉันตั้งชื่อเองตอบด้วยข้อมูลร้านจริง
ส่งต่อให้คนเมื่อเกินขอบเขต และฉันคุมทุกอย่างได้จากหน้า console บนมือถือ ระบบรันบน VPS ของฉันเอง

วิธีทำงาน:
- อ่าน skill "ai-admin-setup" ในโฟลเดอร์นี้ (.claude/skills/ai-admin-setup/SKILL.md หรือ .agents/skills/ai-admin-setup/SKILL.md)
  และ references ของมันก่อนเริ่ม แล้วทำตามขั้นตอนในนั้น
- คุยภาษาไทย ง่าย ๆ ถามทีละข้อ บอกความคืบหน้า "ขั้น x/9" และแสดงหลักฐานว่าแต่ละขั้นผ่าน
- ทำแทนฉันให้มากที่สุด ให้ฉันทำเองเฉพาะ: จ่ายเงิน, พิมพ์รหัส/คีย์ใน Terminal, กดในหน้าเว็บ LINE/ผู้ให้บริการที่ต้องล็อกอิน
- เริ่มด้วยการตรวจว่าทำไปถึงไหนแล้ว (คำสั่ง check และ status) แล้วทำต่อจากขั้นที่ค้าง ไม่เริ่มใหม่
- ฉันจะโยนข้อมูลร้านมาได้ทุกเมื่อ (ข้อความ เมนู รูป PDF ไฟล์ Excel ลิงก์) ให้จัดเก็บเป็นข้อมูลร้านตาม skill
  แล้วสรุปให้ฉันยืนยันก่อนนำเข้าเสมอ โดยเฉพาะราคา

กติกาความปลอดภัย:
1. ห้ามขอรหัส/คีย์/โทเคนในแชท ให้ฉันพิมพ์เองในหน้าต่าง Terminal ด้วยคำสั่งของชุดนี้
2. ห้ามจ่ายเงินหรือกดซื้อแทนฉัน
3. ห้ามแต่งราคา โปรโมชัน หรือนโยบายร้านที่ฉันไม่ได้ให้
4. ก่อนเปิดให้ AI ตอบลูกค้าจริง ต้องลองแชทจนฉันพอใจและถามฉันก่อน
5. ห้ามบอกว่าเสร็จจนกว่าฉันทักจากมือถือแล้วได้คำตอบจริง
6. ไฟล์สำรองฐานข้อมูลมีข้อมูลลูกค้า เก็บในเครื่องฉันเท่านั้น

เริ่มได้เลย
```

---

ไม่มี AI agent? เปิด Terminal ที่โฟลเดอร์นี้แล้วพิมพ์ `bash ai-admin.sh help` (Windows: `powershell -ExecutionPolicy Bypass -File ai-admin.ps1 help`)
แล้วทำตามคู่มือใน `.claude/skills/ai-admin-setup/SKILL.md`
