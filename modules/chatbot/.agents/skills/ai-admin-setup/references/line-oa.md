# ต่อ LINE Official Account

ผู้ใช้ต้องล็อกอิน LINE เอง — คุณบอกทีละขั้นว่ากดตรงไหน แล้วรอผู้ใช้บอกว่าเสร็จ ชื่อเมนูอาจเปลี่ยนตามเวอร์ชันของ LINE
ถ้าผู้ใช้หาไม่เจอ ให้ขอภาพหน้าจอ (ระวังภาพที่มีโทเคน — บอกให้บังก่อนส่ง)

## 1. มี LINE OA แล้วหรือยัง
- ยังไม่มี: สมัครที่ LINE Official Account Manager (manager.line.biz) ด้วยบัญชี LINE ของเจ้าของร้าน ตั้งชื่อ/รูปร้าน
- มีแล้ว: ใช้บัญชีเดิมได้ (แชทเก่ายังอยู่ใน OA Manager)

## 2. เปิด Messaging API
OA Manager → **ตั้งค่า (Settings)** → **Messaging API** → **เปิดใช้ Messaging API** → เลือก/สร้าง Provider (ใช้ชื่อร้าน) → ยืนยัน

## 3. เอาค่าลับสองตัว (ผู้ใช้ใส่เองด้วย `ai-admin secrets`)
เข้า LINE Developers (developers.line.biz) → Provider ของร้าน → channel ของ OA
- แท็บ **Basic settings** → **Channel secret** (ตัวอักษร 32 ตัว)
- แท็บ **Messaging API** → ล่างสุด **Channel access token (long-lived)** → กด **Issue** แล้วคัดลอก
ให้ผู้ใช้รัน `ai-admin secrets` แล้ววางทีละตัว (OpenAI key กด Enter ข้ามได้ถ้าใส่ไว้แล้ว)

## 4. ตั้ง Webhook (AI ทำให้)
`ai-admin line` — ตั้ง Webhook URL เป็น `https://<โดเมน>/webhooks/line` และให้ LINE ยิงทดสอบ ต้องเห็น ✅ "ลายเซ็นถูกต้อง"
- ทดสอบได้ 403 = Channel secret ไม่ใช่ของ channel นี้ → ใส่ใหม่ด้วย `secrets`
- 401 ตอนอ่านข้อมูลบอท = token ผิด/ถูกออกใหม่ → Issue ใหม่แล้วใส่ใหม่

## 5. ตั้งการตอบกลับใน OA Manager (ผู้ใช้กด)
OA Manager → **ตั้งค่า** → **การตอบกลับ (Response settings)**:
- **Webhook: เปิด**
- **ข้อความตอบกลับอัตโนมัติ (Auto-response): ปิด** — ไม่งั้นลูกค้าได้คำตอบซ้อนสองชุด
- ข้อความทักทายเมื่อเพิ่มเพื่อน: เปิดไว้ได้
- โหมดแชท (Chat): เปิดไว้ได้ เจ้าของยังดูแชทใน OA Manager ได้ แต่แนะนำให้ตอบลูกค้าผ่านหน้า console เพื่อให้ AI รู้ว่าคนตอบแล้ว

## 6. เปิดใช้งานจริง
ยืนยันกับผู้ใช้ก่อน ("พร้อมให้ AI ตอบลูกค้าจริงใน LINE แล้วใช่ไหมคะ") → `ai-admin golive on` → ให้ผู้ใช้ใช้ LINE ส่วนตัว
เพิ่มเพื่อน OA แล้วทัก 2–3 ข้อความ → ดูว่าได้คำตอบ และห้องขึ้นในหน้า console · ปิดฉุกเฉิน: `ai-admin golive off`
(หรือปิด AI รายห้องในหน้า console)

## หมายเหตุค่าใช้จ่าย LINE
การตอบกลับทันที (reply) ไม่นับโควตา · ข้อความที่ทีมตอบทีหลัง/บรอดแคสต์ (push) นับโควตาตามแพ็กเกจ OA — ดูได้ในหน้า console
