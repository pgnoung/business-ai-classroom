# ใช้งานประจำวันและต่อยอด

## เจ้าของร้านใช้หน้า console (`https://<โดเมน>/console` เปิดบนมือถือได้)
- **แชท**: เห็นทุกห้อง ห้องที่มีธง "ต้องการคน" = AI ส่งต่อให้ทีม ตอบในห้องได้เลย (ส่งเข้า LINE ลูกค้า)
- **สวิตช์ AI ต่อห้อง**: ปิดเมื่ออยากคุยเองยาว ๆ · เปิดกลับเมื่อจบ
- **คำแก้**: ตอนทีมแก้คำตอบของ AI ระบบเก็บไว้เป็นบทเรียน ให้เจ้าของอนุมัติก่อนเข้าคลังความรู้
- **ออเดอร์**: AI ร่างออเดอร์ คนยืนยัน/อัปเดตสถานะ
- **บรอดแคสต์**: ส่งข้อความถึงกลุ่มลูกค้าตามแท็ก (นับโควตา LINE)
- **ตั้งค่า**: เปลี่ยนรุ่นโมเดล (ดูค่าใช้จ่ายเป็นบาท), ตั้งเวลาทำการ, เพิ่มบัญชีทีมงาน

## งานที่ผู้ใช้จะขอบ่อย
| คำขอ | ทำอย่างไร |
| --- | --- |
| เพิ่ม/แก้/ปิดสินค้า, เปลี่ยนราคา, เพิ่มโปร | แก้ `business/` → แสดงความต่าง → ยืนยัน → `import --apply` → `chat` ไม่ได้แล้วหลัง golive ให้ผู้ใช้ทักทดสอบจากมือถือ |
| เปลี่ยนชื่อ/น้ำเสียง AI | แก้ `business.json` → `import --apply` |
| เพิ่มทีมงาน | หน้า console → ตั้งค่า → บัญชีทีมงาน (เจ้าของทำเอง) |
| สำรองข้อมูล | `backup` (ไฟล์อยู่ในโฟลเดอร์ `backups/` บนเครื่องผู้ใช้) — แนะนำสัปดาห์ละครั้ง |
| อัปเดตเวอร์ชัน | `update` (ดึงเวอร์ชันใหม่ + deploy ข้อมูลเดิมอยู่ครบ) |
| หยุด AI ทั้งร้านชั่วคราว | `golive off` หรือปิดในหน้า console |
| ย้ายไป VPS ใหม่ | `backup` → เช่าเครื่องใหม่ → `connect` ใหม่ → `deploy` → แจ้งผู้ดูแลชุดเรื่องกู้ฐานข้อมูล → `line` |

## ค่าใช้จ่ายที่ผู้ใช้ควรรู้
- OpenAI: จ่ายตามการใช้ ดูยอดประมาณการเป็นบาทในหน้า console และตั้งวงเงินสูงสุดในบัญชี OpenAI ได้
- VPS: รายเดือนตามแพ็กเกจ
- LINE: reply ฟรี · push/บรอดแคสต์นับโควตาตามแพ็กเกจ OA
