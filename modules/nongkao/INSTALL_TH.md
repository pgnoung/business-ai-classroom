# สอนน้องเก้าจากแชต และเชื่อมความรู้กับลูกแพร

สำหรับผู้เรียนที่มีบัญชี Nongkao และเชื่อมร้านใน Scouter แล้ว
ใช้ Codex หรือ Claude Code ที่รัน Terminal ได้ พร้อม Node.js 22 ขึ้นไป
ChatGPT ทั่วไปที่แนบเอกสารได้อย่างเดียวจัดข้อมูลให้ได้ แต่ยังส่งเข้าระบบเองไม่ได้

1. แตก ZIP จะได้โฟลเดอร์ `nongkao-knowledge-sync`
2. **Codex:** วางโฟลเดอร์นี้ใน `~/.codex/skills/`
   **Claude Code:** วางใน `~/.claude/skills/`
   ใช้ macOS/Linux; Windows ใช้ WSL และติดตั้งฝั่ง WSL

   หรือติดตั้งด้วยคำสั่งเดียวจากโฟลเดอร์ที่แตก ZIP:

   ```sh
   node install.mjs both
   ```

   เปลี่ยน `both` เป็น `codex` หรือ `claude` ได้ รุ่นเดิมจะถูกเก็บเป็น backup ไม่ลบทิ้ง
   ตัวติดตั้งไม่ดาวน์โหลดอะไรและไม่เชื่อมบัญชีร้านแทนคุณ
3. เปิดแชตใหม่ แล้วพิมพ์:

   > ใช้ nongkao-knowledge-sync ช่วยสอนน้องเก้าให้ร้านของฉัน ถามฉันทีละคำถาม

4. ครั้งแรก AI จะให้เชื่อมบัญชีผ่าน Terminal ของคุณเอง
   สคริปต์ถามอีเมลและยืนยันส่ง OTP ให้กรอกรหัสใน Terminal เท่านั้น ไม่ส่งรหัสเข้าแชต
5. ส่งข้อมูลสินค้า เงื่อนไข หรือ FAQ ในแชตได้เลย AI จะช่วยจัดรูปแบบ
   ตรวจชื่อร้านและข้อมูล แล้วเลือกบันทึกร่างหรือเปิดใช้ให้ช่วยตอบ

ตัวอย่างคำสั่งหลังเชื่อม:

> นี่คือ FAQ ใหม่ของร้านฉัน ช่วยรวมกับข้อมูลเดิม ตรวจข้อมูลซ้ำ และเอาเข้าร้านนี้เป็นร่างก่อน

> อัปเดตราคาตามไฟล์นี้ ใช้ได้ถึง 31 ธันวาคม 2026 ให้ฉันดูรายการที่เปลี่ยนก่อนเปิดใช้

> ข้อมูลชุดที่ตรวจแล้วนี้ เอาเข้าร้านที่เลือกและเปิดใช้ได้เลย

เชื่อมสองระบบ (AI จะถามร้านและบัญชีของคุณทีละข้อ):

> ใช้ nongkao-knowledge-sync เอาความรู้จากลูกแพรของร้านฉันเข้า Nongkao ให้ฉันตรวจรายการก่อน

> เอาความรู้ร้านจาก Nongkao ไปยัง AI Admin Starter ของฉัน ช่วยเชื่อมบัญชีและนำเข้าให้

ขาเข้าลูกแพรต้องมีชุด AI Admin Starter พร้อม `business/` และตัวช่วย `ai-admin.sh` อยู่แล้ว
ถ้าเป็นระบบรุ่นอื่น AI จะตรวจความเข้ากันได้ก่อน ไม่เขียนเข้าฐานข้อมูลตรง ๆ
ทั้งสองระบบเชื่อมครั้งแรกด้วยบัญชีของคุณเอง รหัสผ่านและ OTP กรอกใน Terminal เท่านั้น
ราคาต้องตรวจรายการอนุมัติ ส่วนวันหมดอายุใน AI Admin Starter ยังต้องทบทวน/ปิดเอง
การซิงก์ทำเมื่อสั่งเป็นครั้ง ๆ ไม่เปิดการเขียนทับสองระบบตลอดเวลา

ห้ามส่งโฟลเดอร์ `~/.config/nongkao-knowledge-sync` หรือไฟล์ input/plan ของร้านไปกับแพ็กแจก
แพ็กไม่มีบัญชี คีย์ หรือข้อมูลร้านของใคร การเชื่อมครั้งแรกทำแยกกันทุกคน
Nongkao ยังใช้แอดมินตรวจและส่งข้อความลูกค้าเอง skill นี้นำเข้าความรู้เท่านั้น
