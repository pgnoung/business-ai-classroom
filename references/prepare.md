# เตรียมก่อนเรียน

ไม่จำเป็นต้องมีครบก่อนเริ่ม AI จะถามเฉพาะที่ขาดและเตรียมส่วนที่ทำได้ก่อน

- คอมพิวเตอร์ที่เปิด Codex/Claude Code และ Terminal ได้; อินเทอร์เน็ต
- ชื่อธุรกิจ ลิงก์เว็บ/เพจ โฟลเดอร์โลโก้ รูปสินค้า เมนู/ราคา FAQ เงื่อนไขที่อนุมัติ
- บัญชี Nongkao ของผู้เรียนและร้านที่เชื่อม Scouter ถ้าจะทดลองนำเข้าความรู้จริง
- VPS ของผู้เรียน; ถ้ามีระบบอื่นบนเครื่องอยู่ ให้แจ้งก่อนติดตั้ง
- โดเมนถ้ามี; ไม่มีให้ตรวจทางเลือกในตัวติดตั้ง
- บัญชี OpenAI ที่มีสิทธิ์ API/เครดิต (ไม่ใช่ถือว่าค่าสมาชิกแชตครอบคลุม API)
- LINE OA ที่มีสิทธิ์จัดการ Messaging API แนะนำแยก OA ทดสอบ
- เมื่อถึง Content Studio: บัญชี Make, OpenAI และสิทธิ์เพจ Facebook

ลิงก์ทางการสำหรับเข้าใช้งาน (ต้องตรวจสถานะ/แพ็กปัจจุบันก่อนแนะนำหรือซื้อ):
- https://nongkao.tkd-crm.com
- https://manager.line.biz
- https://developers.line.biz/console/
- https://platform.openai.com
- https://www.make.com
